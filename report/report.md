## 三、实验整体逻辑分析

### 3.1 本章节的逻辑主线

本实验围绕“Trap 进入 → 保存上下文 → 调用 C 处理函数 → 分类处理中断或异常 → 恢复上下文 → 返回原执行流”展开。以下为依据指导书整理的计划，实际理解和实现分析待完成实验后补充。

### 3.2 功能的逐步实现

1. 迁移 Lab2 必需的物理内存管理实现，并核对其依赖和环境兼容性。
2. 对照 `SAVE_ALL` 和 `struct trapframe` 实现 `RESTORE_ALL`，补齐 `__alltraps` 对 `trap()` 的调用。
3. 实现中断和异常分派后的处理，保证时钟持续触发以及异常返回位置正确更新。
4. 编译并运行真实验证，记录结果、错误、修复和截图。
